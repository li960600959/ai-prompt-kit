# ai-prompt-kit · AI 自媒体创作提示词模板集

一套可直接复用的 AI 提示词模板，覆盖自媒体内容生产的五个关键环节。把 `{{...}}` 换成你的具体内容即可。

## 目录
| 文件 | 环节 | 用途 |
|---|---|---|
| `prompts/01-xuan-ti.md` | 选题 | 生成带钩子的爆款选题 |
| `prompts/02-xie-gao.md` | 写稿 | 写 200–260 字口播/图文稿 |
| `prompts/03-biao-ti.md` | 标题 | 生成 10 个爆款标题 |
| `prompts/04-kou-bo.md` | 口播稿 | 央视播报腔口播脚本 |
| `prompts/05-fu-pan.md` | 复盘 | 每日结构化复盘 |

## 用法
1. 打开对应模板
2. 把 `{{领域}}`、`{{选题}}` 等占位符替换为你的内容
3. 整段发给任意大模型（ChatGPT / 通义 / Kimi 等）
4. 产出即草稿，按需微调

## 原则
- 模板只给框架，**判断权在你**（选题方向、价值观、合规底线）
- 配合 `ai-koubo-video` 出片、`ai-wechat-draft` 排版，构成完整生产链
